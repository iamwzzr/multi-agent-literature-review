# 报告展示与文献范围修复（2026-11-18）

本次仅修改后端、后端测试及说明文档。前端源码未修改。

## 处理的问题

- 同类正文主张合并到同一章节，每条仍为独立段落并保留引用；避免重复“研究发现”“综合分析与比较”标题。
- 比较表行标为 `presentation=comparison_row`，继续进入原文审核及版本门禁，但不重复展开为正文。结构化比较表继续由既有前端接口展示。
- 比较条件不再转成 Python 字典字符串；空条件不展示，空表格单元显示“未知（未报告）”。兼容模型偶然写入的扁平字典形式适用范围。
- 解码 HTML 字符实体，并在引用校验之前执行同样的解码，防止编码后的引用绕过校验。保留原始证据和审核记录。
- 短引文回退告警按交付状态展示：完成有效审核后，不再保留“仍须原文审核”的过期表述；仍提示引用精度需要人工复核。
- 提取问题中明确点名的英文方法，优先为强题名匹配保留候选名额；同名词在其他论文中的引用不等于该方法的原始论文。
- 区分本地全库索引数量、本轮选入文献和实际取得的原文证据。完整目录保留本地审计，模型仅接收范围摘要，避免补证轮上下文膨胀。
- 新增程序审核：将本轮证据缺口扩大为“本地不存在某论文”的断言会形成阻塞性范围问题，即使模型 Reviewer 判为通过也不能交付为通过。
